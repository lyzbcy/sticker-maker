## 生图方案选择

### 方案 A: OpenAI DALL-E API（推荐）

**优点：**
- API 稳定，效果好
- 云端运行，不需要显卡
- 容易部署到服务器

**缺点：**
- 需要付费 API key
- 按次计费

**成本：**
- DALL-E 3: $0.04/张 (1024x1024)
- 每天4张四宫格 = $0.16/天
- 每月约 $5

**代码：**
```python
import openai

client = openai.OpenAI(api_key="sk-xxx")

response = client.images.generate(
    model="dall-e-3",
    prompt="像素风格表情包，四宫格布局...",
    size="1024x1024",
    quality="standard",
    n=1,
)

image_url = response.data[0].url
```

### 方案 B: Stability AI API

**优点：**
- 支持像素风格
- 支持 image-to-image（风格一致性更好）

**缺点：**
- 需要 Stability AI 账号

### 方案 C: 本地 Stable Diffusion

**优点：**
- 完全免费
- 无限生成

**缺点：**
- 需要 GPU 服务器
- 配置复杂

### 2. main.py

```python
"""
主入口
"""

import yaml
from image_generator import ImageGenerator
from image_processor import ImageProcessor
from publisher import Publisher

def load_config():
    with open('config/config.yaml') as f:
        return yaml.safe_load(f)

def main():
    # 1. 加载配置
    config = load_config()
    
    # 2. 初始化模块
    generator = ImageGenerator(
        provider=config['image_generation']['provider'],
        api_key=config.get('secrets', {}).get('openai', {}).get('api_key')
    )
    processor = ImageProcessor()
    publisher = Publisher()
    
    # 3. 获取当前弹数
    current_episode = get_current_episode()
    output_dir = f"./output/星星布丁第{current_episode}弹"
    
    # 4. 创建文件夹
    create_folders(output_dir)
    
    # 5. 生成图片
    for i in range(3):  # 生成3组四宫格
        print(f"生成第 {i+1} 组四宫格...")
        quad_image = generator.generate_quad_image(
            base_image=config['project']['base_image'],
            reference_images=get_reference_images()
        )
        
        # 6. 裁剪
        images = processor.crop_quad(quad_image, f"{output_dir}/原图/", start=i*4+1)
    
    # 7. 发布
    if config['publish']['auto_publish']:
        publisher.publish(output_dir, current_episode)
    
    # 8. 通知
    send_notification(f"✅ 星星布丁第{current_episode}弹 已发布！")

if __name__ == "__main__":
    main()
```

- CPU: 2核+
