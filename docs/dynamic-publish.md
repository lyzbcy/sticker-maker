# GIF动态投稿
- 最终版目录支持PNG或GIF，整套自动识别；同套混合格式阻止提交。保持原GIF字节，不转PNG、不改速度。
- 动态预检：8/16/24张、240×240、多帧真实GIF、无限循环、逐帧可解码且时长有效、单图≤500KiB、无字节重复、含义映射完整按数字顺序。
- 新建表单按本套选择动态/静态；提交前按同一类型核对，读取失败阻止提交。编辑已有动态同样校验动态类型，不自动改变原专辑类型。
- 图片发现、详情预览、资源行计数、规范工程/旧库及辅助素材生成共用media.final_stickers。静态生成/修图算法保持PNG；动态不走静态修图，辅助封面/横幅为静态图。
- 账号与角色、资源锁、完整格数/含义、重复拒收、未知提交核销沿用原路径。无新AI/人工评分。
- 外部素材使用现有资源库复制导入：将带meta.json、meaning_map.json、介绍及投稿辅助素材的episode目录导入当前账号；不转换或清理原库。
- 用例：tests/publish/test_dynamic_publish.py。实测与安装/投稿回执：../../../09-归档/动态投稿支持-20261027。

