# E. 推广系统 — 设计文档（Spec）

> **子项目**：E（5 个子项目的最后一个）
> **依赖**：B 的 .app 界面（E 在里面展示）

## 0. 职责

两个推广维度（初心第 84-88 行）：
1. **表情包推广**：软件里多用"所有表情/精选"目录的精选表情（138 张）做展示
2. **个人推广**：参考 lyzbcy-study-map 的三码设计——赞赏二维码 / 入群二维码 / 表情包二维码

## 1. 关键决策

| # | 决策 | 选择 | 理由 |
|---|---|---|---|
| E1 | 精选表情 | **内置进分发包**（resources/featured/） | 初心第 85 行明确"多用精选"，粉丝开箱可见 |
| E2 | 三码 | **配置化**（默认你的，可自定义） | 跟 C 的赞赏图一致策略 |
| E3 | 展示位置 | 主界面轮播 + 结果页推荐 + "关于"页三码 | 多触点 |
| E4 | 三码资源 | **不内置**（你的私人码不分发） | 隐私；粉丝软件里默认空，你自己的开发版填 |

## 3. 精选表情展示

`featured.py`：
- `list_featured() -> list[Path]`：返回内置精选表情（随机 N 张）
- 打包进 resources/featured/（从现有"所有表情/精选"复制）
- 主界面 MainScreen.vue 加 `<FeaturedShowcase>`：显示 8 张精选缩略图轮播
- 结果页加"你可能还喜欢"：随机 4 张精选

## 4. 三码（PromotionConfig）

```python
@dataclass
class PromotionConfig:
    reward_qr: Optional[Path] = None     # 赞赏二维码
    group_qr: Optional[Path] = None      # 入群二维码
    sticker_qr: Optional[Path] = None    # 表情包下载二维码
```

默认全 None（粉丝软件不展示私人码）。开发者（你）在 prefs 或本地配置填路径，开发版"关于"页显示三码。

AboutPanel.vue：三栏 grid，有图显示二维码 + 文案，无图隐藏。
