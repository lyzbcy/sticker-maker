# 表情包一键制作使命收口 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把已分散实现的生图、发布、Agent、推广、安装和更新能力收口成普通用户可在 Mac 桌面软件内完成的闭环。

**Architecture:** 保持 Electron/Vue 界面 + JSON-lines 常驻 Python 引擎。业务规则、发布、Agent 和 50 条环形日志统一由 Python CLI 暴露；Electron 只处理本机窗口、文件选择、更新和状态展示。

**Tech Stack:** Python 3.9+、pytest、Pillow、Playwright、Flask、APScheduler、Electron 30、Vue 3、Pinia、Vitest、PyInstaller、electron-builder。

def _pick_weighted_without_replacement(names, probs, count, rng):
    pool = list(names)
    result = []
    while pool and len(result) < count:
        weights = normalize_probs({name: max(0, probs.get(name, 0)) for name in pool})
        chosen = _pick_by_probs(weights, rng)
        result.append(chosen)
        pool.remove(chosen)
    return result
