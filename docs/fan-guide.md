# 粉丝上手：先做一组，再决定是否投稿

0.5.1已正式发行。下载入口：https://lyzbcy.github.io/sticker-maker/ 。Windows x64与Apple Silicon（M系列）分别提供独立包。

1. Windows 下载 `sticker-maker-win-v0.5.1-setup.exe`，双击。安装界面优先推荐非系统盘，也可以点“更换位置”；桌面快捷方式和完成后打开由你选择。Apple Silicon（M系列）Mac 下载独立 Mac 包，不要打开 Windows 的 exe。
2. 首次打开检测生图工具。没有安装时点“一键安装 codex”；Windows 不需要先装 Python、Node.js。下载安装时显示已下载兆数，网络慢可稍后重试。
3. 已安装但未登录时点“打开登录窗口”，完成自己的 ChatGPT 登录，再点“我已登录，重新检测”。软件不是免费生图额度，不附赠账号；实际生成使用你自己的账号及可用额度。
4. 先使用内置角色或上传自己的角色图片；概率会自动按比例调整，第一次保留默认值即可。
5. 点“开始生图”，先做一组。等待时底部显示当前阶段和已用时间，可以展开、复制日志。
6. 成功后点“保存表情包 ZIP”，选保存位置。解压后“最终版”目录是表情图片，添加到聊天软件即可；不需要微信创作者账号。
7. 想投稿时再配置自己的微信表情开放平台账号，检查角色与素材，再点“一键提交微信”。投稿成功与审核通过是两个不同结果；默认批量不会自动提交。
8. 遇到问题点“遇到问题反馈”，写留言，检查日志预览再发送；断网保留留言，可重试或复制诊断信息。
9. 旧0.5.0或更早客户端先手动安装一次此修复版，以获得新的更新交接功能。用户作品与设置保留；网络失败不会误报更新完成。

首次系统确认：Windows包未代码签名，系统可能显示未知发布者；Mac包使用ad-hoc签名，未Apple公证。请核对官方发布页与SHA。Mac被系统拦截时，参考[Apple官方操作说明](https://support.apple.com/zh-cn/102445)。干净CI安装通过不等于所有电脑环境一致。

生成结束先预览含义与画面、透明边缘，再导出；生成完成不保证每张图都达到平台审核或使用效果要求。
