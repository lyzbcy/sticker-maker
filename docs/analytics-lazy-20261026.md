# 数据看板按需加载与原图分析 · 0.6.5
现状：源码0.6.5，构建/本机升级验收见本轮VERIFICATION；负责人：本设备维护；最后更新：2026-10-26。

## 改动
- 单图get_sticker_metrics新增paginated请求：默认固定20条，支持offset、query、sort、observation；兼容旧无分页请求。sync_sticker_metrics接受paginated后仅返回同步计数/状态，再按页读缓存，不把7753条再传一遍。
- 本机按账号、可见作品及缓存mtime/size复用解析结果，外部同步更改会失效；翻页仅为可见20行读取图片文件。不自动向平台抓取。
- 整套排名每页20套且封面懒加载；单图20行原图采用loading=lazy、async解码，点击大图；浅响应式缓存避免全量深层代理。不重复刷新已经存在的作品列表和收益。
- 搜索含义/作品（250ms防抖）、发送最多/最少、筛选内发送占比、有发送和零发送统计，仍按同抓取日和平台日期比较。不把单日量混为累计，不把缺失补为0。
- 图片只在当前可见作品范围内解析。优先平台MD5与本地最终图字节匹配；平台可能重新编码PNG，字节不同仅以已关联平台含义与本套唯一完全相同文件名展示“本地同含义原图”，不冒充平台字节原文件、不用模糊名称或序号猜图。缺失/破图明确显示。
- 分页失败保留已显示页及其排名，过时响应不覆盖新范围；卸载清理监听和搜索定时器。刷新、逐套进度、取消及失败保留缓存继续有效。
