# 微信表情几件事处理记录

来源是桌面《微信表情几件事.docx》，本轮仅读取Word原件。文档在执行期间新增第五项“不使用Actions、本地构建”，最终核对时已补齐。源码和本地双端候选更新为0.6.2，本轮没有正式发布、投稿、预约或清理真实表情素材。原0.6.0工程瘦身及0.6.1资源位置引导保留。

## 双端架构

所引架构规范的正文要求PC软件同时支持Mac和Windows。当前采用同一套Vue界面、Electron受控IPC及Python引擎，平台差异集中在路径、凭据、安装器、浏览器发现和打包入口。两台机器的294份业务与构建输入文件SHA一致，双端冻结引擎各11个关键模块与源码语义一致，不需要维护两套业务代码。

同一源码分别产出Windows x64安装包及Mac ARM64应用包。PyInstaller需要在目标平台冻结，不能把Windows生成的引擎直接放进Mac应用。本次Windows在本机打包，Mac通过SSH在Apple Silicon Mac原生打包，均实际运行并验收。没有调用GitHub Actions。原有CI配置仅保留，不作为本轮构建或发版步骤。

## 教程和高频入口

教程五个步骤均在顶部保留可见的退出按钮，不要求Codex检测成功或保存配置才能退出。问题与警告页说明生图、发布浏览器、发布账号及资源位置的状态和影响，提供对应安装、登录、设置或资源连接入口。直接进入发布账号处理时会读取当前已保存状态，避免误报未配置。

制作、作品库、全部表情、问题与警告改为顶部常驻标签。长列表滚动时标签保持可见，全部表情无需再到页面底部寻找。长任务的同步、安装和资源处理也会显示实时阶段与耗时。

## 安装包

0.6.1安装包448100974字节；0.6.2约205 MB，最终大小与SHA见 verification/docx-tasks-20261021/artifacts.json。减小约54%。解包体积从1343923214字节降至约588 MB，具体目录统计见 package-breakdown.json。比较均为同机Windows候选，不把压缩包和解包大小混算。

旧包的内置浏览器约753 MB，包含完整Chromium、另一套无头浏览器和配套文件。新包默认不重复携带浏览器，优先使用本机Edge或Chrome；缺少时明确提示按需安装可选Chromium组件，组件安装不再重复下载无头壳。旧式全内置构建仍可显式设置 STICKER_BUNDLE_BROWSERS=1，默认发行与候选均不设置。

Mac原生构建另修正了旧脚本无条件复制浏览器的问题；Mac安装脚本统一LF换行并设置可执行权限，避免Windows工作副本的CRLF导致双击或执行安装失败。

固定自动化脚本仍需要执行它的Playwright库及驱动；可以分离的是浏览器二进制。本软件还包含生图调用、切图、去背景、素材生成、评分与工程管理，所以保留Electron、Python、Pillow、NumPy/SciPy、Playwright及必要资源。没有为了缩小体积删除图像处理、账号校验、投稿门禁或提交结果核销功能。

## 本地构建与交付

严格按文档第五项处理：本轮未运行Actions、未推送远端标签或公开发布。Windows安装包204909564字节，Mac包230049160字节；两份最终文件已放在 outputs/desktop-usability-0.6.2，SHA见验收目录artifacts.json。

Mac构建目录在本机Library/Caches，源码使用校验过的冻结工作副本，不在Syncthing目录内写入node_modules或构建缓存。可复用脚本是 scripts/build-local-mac.py，支持从失败的构建阶段续接；使用Mac本机Python3.12虚拟环境与Node，完成测试、冻结、打包、ad-hoc签名、真实IPC、隔离安装及ZIP交付。Mac包未做Apple公证，属于本地签名候选；没有替换任一设备的正式安装。
