# 表情包一键制作 0.6.13

本次汇总 0.6.6 之后的开发更新，并修复发行回归中发现的 GIF 流程缺失。发行状态与验证结果以 current-state.md 最新记录为准。

- 资源库界面按功能拆分；取消选择目录时保留已有预览，防止重复操作，离开页面后停止自身监听与轮询。
- 修复任务完成后仍显示旧进度、设置页打开时误保存，以及资源刷新成功后仍残留旧读取错误的问题。
- 反馈复制遵循日志勾选，复制失败时保留内容并支持重试。
- 支持导入已有 GIF 动态专辑并按原文件投稿；检查数量、尺寸、帧、循环、文件大小、重复及含义顺序。动态与静态混合时阻止提交，动态文件不走静态修图。
- 缩短 Windows 资源物化的临时路径，减少深目录下的路径长度问题。
- 上架预检区分平台名单读取失败与非候选作品的本地回写警告，保留候选作品与未知结果保护。
- 指定角色分类修复核对原平台作品身份与最新审核理由，仅修改明确指定的分类。

GIF 投稿支持不等于已加入一键动画生成。既有素材、评分、账号和资源库数据保留；本次软件发行不自动投稿作品或发送反馈。

支持 Windows x64 和 Apple Silicon Mac。Mac 使用本地 ad-hoc 签名，未 Apple 公证；不提供 Intel Mac 包。
