# 固定AI评分标准 v1.0（历史）

**2026-10-14更新：用户反馈这些分数虚高，改为每10弹人工检查。当前流程见[人工评分表](human-rating-batches.md)。下文保留当时规则与结果，不是当前验收标准。**
用户选择“采用固定AI标准，AI分单独记录”。这次是主观AI视觉评审，不是人工评分或收益、审核预测；应用版本仍0.5.13。

## 输入与公式
- 每弹实际最终16张240×240主图和封面/图标/横幅/赞赏引导/赞赏致谢5素材；逐文件SHA绑定。
- 五个逐图维度：构图完整25、表情/肢体20、图词匹配20、聊天用途20、背景洁净10；软件素材整弹5，总分100。
- 每维0不可用、1明显缺陷、2可用但有缺陷/语义含混/用途窄、3良好但轻微瑕疵/常规、4清楚完整匹配且未见缺陷。
- 总分=各维权重×16张等级合计/64 + 5×资产等级/4。保存未舍入值和两位小数。
- 有意半身/头像不按缺脚扣分；透明图必须alpha合成，隐藏RGB黑像素不算可见黑边。严重异常另标hard_defects，不被总分抵消。
- 冻结rubric SHA：`9e76241f7ac48d7072d121c3ac8797d456f0580a3bf47f6e71afb29173bbbca4`。既定权重不随序号调整，也不为递增修改旧分。

## 记录、比较与续接
- `ai_quality_score`是AI分；`human_score`独立，当前1—8仍null。逐图等级/理由、资产评语、SHA和规则版本保存在[phase14](../verification/ai-review-phase14-20261014/ai-reviews.jsonl)。
- `cmd_save_rating`写人工rating.json，本流程不调用它。生产作品和rating.json原SHA全部保留。
- 相邻比较固定按实验弹号1→8跨类型进行；严格使用未舍入分数new>previous，展示用两位小数。它不是相同角色/类型受控因果实验。
- 1—8是已投稿历史的事后评分；7次相邻比较仅4次提高，历史严格递增不成立。既有投稿不因后评低分重投。
- 原定候选9以AI相邻提高作门禁的流程已被本轮人工评审要求替代；旧分/文件SHA保留，不再以AI高分宣布合格。
- 若以后新增维度或更换量表，另建新版本并全量复评，旧记录保留；同规则也存在AI主观评分漂移，不等同可保证100弹不断提高。
