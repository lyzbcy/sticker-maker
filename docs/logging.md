# 本地诊断日志

按 `E:/共享/tools/软件开发/软件组件/日志系统.md` 接入。Node 日志模块是 `desktop/src/main/diagnosticLog.js`，仅依赖 Node 内置模块与旁边的 `diagnostics.js` 脱敏函数；可独立用于 Windows 和 Mac。Electron 主进程负责接收引擎进度、命令结果、Agent日志和界面活动，渲染进程通过受控 IPC 查询与导出。

普通记录先入内存，每5秒或累计64 KB批量追加文件；没有新记录时不写盘。错误触发尽快写出，正常退出等待缓冲写完。使用操作系统的文件缓存，不逐条强制刷物理磁盘。突然断电或主进程被强杀时，最后几秒尚未写出的记录可能丢失，此前已写入的记录在下次启动仍可查询。

文件在本机 Electron userData 下的 diagnostics，独立于资源库与规范工程。单文件约2 MB轮转，总量最多20 MB、保留7天；自动清理旧文件。日志队列限制512 KB，磁盘不可写时保留有界内存记录并向问题页显示错误，避免写盘失败导致无限占用内存。

默认记录命令名、阶段、耗时、完成或失败及异常说明，不记录完整命令参数或凭据返回值。问题与警告页可开启详细排障模式，额外记录脱敏后的步骤上下文；开关只在本机保存，不随工程同步。写入前移除常见密钥、口令、邮箱、链接查询参数和本机绝对路径，导出内容保持脱敏。

界面底部实时显示正在执行的任务、阶段消息、已用时和有依据的步骤进度。无法可靠估算剩余时间时显示待估算，不用固定倒计时冒充真实进度。可以展开查看本次活动；完整诊断文件可在问题与警告页或反馈页导出。

反馈页从本地记录生成摘要，包括此前运行的上下文；预览内容就是实际附带的日志摘要，不再固定取30条后暗中截到1000字符。摘要按服务端9000字节文本限制随留言长度调整，超过编码限制时明确报错，保留留言；完整记录以本地导出提供，不自动上传完整文件。本轮未发送真实反馈。

独立模块的基本使用方式：创建 DiagnosticLog，await init()，调用 log({ stage, message, level })；需要更多上下文时开启 setDebug(true) 并传 details；正常退出必须 await close()。测试覆盖批处理定时、错误写出、跨运行保留、轮转清理、脱敏和写盘失败。
