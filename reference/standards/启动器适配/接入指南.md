# 以后开发软件，从这里接入启动器

新增这套规范，是为了让软件构建、安装识别、下载和展示使用一致信息。无需将所有软件搬到同一个开发目录。

## 给开发 Agent 的一句话

> 开发时读取 `E:\共享\tools\软件开发\启动器适配\laoyu-launcher-adapter\SKILL.md`，按规范接入捞鱼软件中心；完成后运行严格自查，并分别报告包检查、启动器登记和实际运行验收结果。

这是可直接按路径调用的 skill，尚未自动安装到全局 skill 列表。已在“软件组件/软件对应开发 skill.md”添加入口；各软件自己的 SKILL.md 也应在接入时加上这个入口。

## 文件位置

- `laoyu-launcher-adapter/SKILL.md`：开发步骤。
- `laoyu-launcher-adapter/references/适配规范.md`：产品 ID、主程序、安装登记、发布包、图标和视频规范。
- `laoyu-launcher-adapter/assets/launcher-adapter.example.json`：复制到新软件根目录后填写。
- `laoyu-launcher-adapter/scripts/check_adapter.py`：只读自查，Python 3 标准库；完整集成检查另需 Node.js。
- `laoyu-launcher-adapter/scripts/self_test.py`：检查自查脚本自身的关键失败场景。
- `verification/airpods-buddy.local.json` 与 `airpods-buddy-report.json`：使用本机真实 1.9.21 发布包的样例与报告。包含本机绝对路径，换电脑需调整。

## 自查命令

把“软件项目路径”替换为实际软件目录，在 PowerShell 执行：

```powershell
python 'E:\共享\tools\软件开发\启动器适配\laoyu-launcher-adapter\scripts\check_adapter.py' '软件项目路径\launcher-adapter.json' --launcher-root 'E:\共享\创业\捞鱼软件中心' --strict --report '软件项目路径\verification\launcher-adapter-report.json'
```

退出码 0 才是严格自查通过；1 有错误；2 有未完成事项。已安装的软件可以加 `--installed`，只读调用启动器自动识别，不执行软件。完整 JSON 报告适合发版前留档。
