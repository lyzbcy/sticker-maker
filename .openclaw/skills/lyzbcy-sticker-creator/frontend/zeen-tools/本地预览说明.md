# 表情包概率控制台 · 本地预览说明

## 功能

实时查看和调整 `lyzbcy-sticker-creator/config.yaml` 中的三种概率：

| 概率组 | 说明 | 默认值 |
|--------|------|--------|
| 模式概率 | 单人/双人/四人 的选择比例 | 70% / 25% / 5% |
| 角色概率 | 单人模式下各角色权重 | 星星布丁75% / 捞鱼20% / 周三涵3% / 周五涵2% |
| 衣服概率 | 星星布丁的 base3/4/5 版本 | 60% / 20% / 20% |

## 启动

双击 `一键启动前端.bat` → 自动安装依赖 → 启动服务器 → 打开浏览器

## 关闭

双击 `一键关闭前端.bat` → 关闭 Node 服务器进程

## 手动启动

```bash
cd frontend
npm install
npm start
```

浏览器打开: `http://localhost:3412`

## 技术栈

- 后端: Node.js (http + js-yaml)
- 前端: 原生 HTML/CSS/JS（无框架依赖）
- 端口: 3412
- 配置文件: ../config.yaml（本 skill 目录下）
