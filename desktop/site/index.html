三下就装好

下载的是 zip，里面只有应用和快捷安装文件。快捷安装会处理 macOS 隔离提示、复制到「应用程序」并自动启动。

下载 v0.2.0
1

解压 zip

双击下载的压缩包，保持 `.app` 和 `install.command` 在同一个文件夹。

2

双击快捷安装

系统若询问权限，按提示允许；安装器会自动复制并启动应用。

3

按向导检查 Codex

软件会先检测安装、登录和生图链路；未就绪时给出对应设置提示。

↻

以后可一键更新

发现新版本时在软件内点击「一键更新」，无需重新寻找下载文件。

让你的 AI Agent 接手重复工作

在软件的「发布与 AI 工具」中启用服务，复制 token 和现成 prompt。服务只监听本机地址，默认不会开放给局域网。
